# 01_Data

**Raw input reads — read-only. Do not modify these files.**

- `isolate_A.fastq`
- `isolate_B.fastq`
- `isolate_C.fastq`

Each is a set of Oxford Nanopore **amplicon** reads produced by abutting-primer PCR on an
RCA-enriched (circular DNA) template. Any filtered, trimmed, downsampled or otherwise
derived reads must be written to `03_analysis/`, never here.
