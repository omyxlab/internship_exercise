# 03_analysis

Your workbench: intermediate and working outputs. Examples:
- QC reports and read-length/overlap inspection
- filtered / trimmed / downsampled reads
- assembly or consensus attempts (including ones that did not work — keep them)
- mappings, alignments, BLAST hit tables, tree inference files

Keep this organised (e.g. a subfolder per isolate or per stage). Only the final,
report-ready outputs get promoted to `04_results/`.
