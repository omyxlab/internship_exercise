# 04_results

Final, report-ready outputs only — the files your `REPORT.md` points to. Expected:

- `isolate_A.fasta`, `isolate_B.fasta`, `isolate_C.fasta` — the finished, circular genomes
- annotation tables / feature files (ORFs: Rep, CP; conserved motifs)
- identity matrices at **three levels**: whole-genome, Rep, CP
- closest-GenBank-match table (accession, description, % identity)
- final phylogenetic trees / figures, if produced
- a per-isolate summary table (length, GC%, ORFs, best hit)

Nothing here should require re-running by hand — it must all be regenerated by the scripts
in `02_scripts/`.
